# 프롬프트 템플릿 모음

이 디렉토리에는 재사용 가능한 프롬프트 템플릿이 저장되어 있습니다.

## 📁 사용 가능한 템플릿

### 1. `task-breakdown.md` - 작업 분해 템플릿

복잡한 개발 작업을 작은 단계로 분해하는 프롬프트입니다.

**사용 방법:**
1. 파일을 열어서 `[여기에 작업 내용 입력]` 부분을 실제 작업으로 교체
2. 전체 내용을 복사하여 Claude에게 전달
3. Claude가 체계적인 작업 계획을 생성합니다

**예시:**
```markdown
## 🎯 작업 목표

도시 상세페이지를 만들고 싶어
```

**결과물:**
- Phase별 작업 목록
- 각 작업의 목적, 변경사항, 검증 방법
- 의존성 다이어그램
- 위험 요소 및 대응 전략

---

### 2. `feature-breakdown.md` - 기능 분해 템플릿 (고급)

복잡한 기능을 체계적으로 분석하고 실행 가능한 작업으로 분해하는 프롬프트입니다.

**사용 방법:**
1. 파일을 열어서 `$ARGUMENTS` 부분을 구현하고 싶은 기능으로 교체
2. 전체 내용을 복사하여 Claude에게 전달
3. Claude가 포괄적인 구현 계획을 생성합니다

**예시:**
```markdown
## 구현하고 싶은 기능

**도시 리뷰 시스템 구현**
```

**결과물:**
- 🎯 기능 분석 (핵심 목표, 범위, 시나리오)
- 🏗️ 아키텍처 분해 (프론트엔드/백엔드/외부 연동)
- 📋 작업 분해 (우선순위, 시간, 의존성)
- 🔄 의존성 관계 (병렬/순차 처리)
- 🧪 검증 계획 (테스트 전략)
- 📊 진행 추적 (마일스톤, 리스크)
- 🚀 배포 전략 (스테이징, 모니터링)

---

### 3. `github-issue.md` - GitHub 이슈 생성 템플릿

명확하고 구조화된 GitHub 이슈를 생성하는 프롬프트입니다.

**사용 방법:**
1. 파일을 열어서 `[여기에 이슈 내용 입력]` 부분을 실제 이슈로 교체
2. 전체 내용을 복사하여 Claude에게 전달
3. Claude가 구조화된 이슈를 생성합니다

**예시:**
```markdown
## 🎯 이슈 내용

**로그인 후 리다이렉트가 작동하지 않아**
```

**결과물:**
- 이슈 타입 분류 (Bug/Feature/Enhancement)
- 우선순위 결정
- 구조화된 이슈 본문
- 구현 체크리스트
- 기술적 세부사항

---

### 4. `solve-github-issue.md` - GitHub 이슈 해결 계획 템플릿 ⭐

GitHub 이슈를 가져와서 분석하고 상세한 해결 계획을 수립하는 프롬프트입니다.

**사용 방법:**
1. 파일을 열어서 `$ARGUMENTS` 부분을 이슈 번호로 교체
2. 전체 내용을 복사하여 Claude에게 전달
3. Claude가 이슈를 가져와서 분석하고 해결 계획을 수립합니다
4. 계획을 검토하고 승인합니다

**예시:**
```markdown
## 🎯 해결할 GitHub 이슈

**이슈 번호: 123**
```

**프로세스:**
1. 🔍 GitHub CLI로 이슈 정보 가져오기
2. 📊 이슈 분석 (유형, 우선순위, 핵심 문제)
3. 🔎 코드베이스 조사
4. 🔧 해결 방안 설계
5. 📝 상세 실행 계획 수립
6. ⚠️ 리스크 평가
7. 🧪 검증 계획
8. ✋ 사용자 승인 요청

**결과물:**
- 이슈 분석 보고서
- 기술적 결정사항 및 대안 검토
- Phase별 상세 실행 계획 (체크리스트)
- 리스크 평가 및 대응 방안
- 검증 체크리스트
- 사용자 승인 절차
